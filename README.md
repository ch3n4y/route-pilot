# RoutePilot（路由领航）

Windows 本地多网关路由管理工具。通过浏览器界面管理目标网段、出口网关和网关优先级。

## 功能

- 配置 IPv4 网段与一个或多个出口网关
- 拖拽调整同一网段内网关优先级
- 自动写入和校验 Windows 活动路由
- 自动清理与已配置网段冲突、但不受本程序管理的路由
- 本地监听、系统托盘常驻、单实例运行

## 使用

1. 从 [Releases](../../releases/latest) 下载 `RoutePilot.exe`。
2. 右键选择“以管理员身份运行”。
3. 程序会自动打开本地管理界面。
4. 在“网段管理”中选择多个网关，并拖拽调整优先级。

> 应用只监听 `127.0.0.1`。修改系统路由需要管理员权限。

## 本地构建

依赖：Go、Node.js；可选安装 UPX 以压缩可执行文件。

```powershell
./build.ps1
```

输出文件：`路由管理.exe`。
